# PO Auto Signals

واجهة عربية قابلة للتثبيت كتطبيق PWA على iPhone، لعرض تحليل فني متعدد الأصول.

## الميزات
- واجهة RTL متجاوبة مع الجوال.
- أصول افتراضية تشمل XAUUSD والعملات وUS30 وNAS100 وSPX500 وDAX40.
- اتصال WebSocket قابل للضبط حسب وثائق مزود البيانات.
- استقبال رسائل JSON مفردة أو مصفوفات، مع دعم حقول شائعة مثل `symbol`, `price`, `bid`, `ask`, `last`, `timestamp`.
- EMA 5/13 وRSI 7 والزخم، وإشارات CALL/PUT/انتظار.
- تنبيه صوتي وسجل وتصدير CSV.
- PWA وService Worker للتخزين المؤقت والعمل دون اتصال للواجهة.

## تشغيل محلي
افتح الملفات عبر خادم HTTPS أو localhost؛ Service Worker لا يعمل عادةً من `file://`.

## ربط مزود الأسعار
1. احصل من مزودك على WebSocket URL وصيغة رسالة الاشتراك وصيغة الرسائل الواردة.
2. أدخل العنوان في خانة WebSocket ورسالة الاشتراك كما هي موثقة من المزود.
3. حدد مسار الرمز والسعر في خانة المسار. الافتراضي `symbol,price`؛ مثال لبيانات متداخلة: `data.symbol,data.bid`.
4. إذا كانت الرسالة تحتوي `bid` و`ask` فقط دون `price`، يحسب التطبيق متوسطهما تلقائياً.
5. تأكد أن أسماء الرموز تطابق كتالوج مزودك؛ بعض المزودين يستخدمون لاحقات أو رموزاً مختلفة للمؤشرات.

**لا يوجد مزود أسعار مدمج في هذا المستودع.** لا تضع مفاتيح API السرية في الواجهة الأمامية العامة. استخدم مزوداً يسمح باتصال المتصفح أو وسيطاً آمناً على خادمك. لا يمكن ضمان توافق الأسعار مع Pocket Option، خاصة OTC.

## النشر على GitHub Pages
من إعدادات المستودع: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. بعد اكتمال النشر افتح رابط Pages في Safari ثم Share → Add to Home Screen.

## تنبيه
هذا برنامج معلوماتي وتجريبي، لا ينفذ صفقات ولا يتصل بحساب Pocket Option. الإشارات ليست توصيات مالية ولا تضمن نتيجة. اختبر على حساب تجريبي.
